# Contributing

- Owner: Engineering Lead role, initially the Product Architect
- Status: Active
- Update rule: update when CI, branch or review policy changes

Read `AGENTS.md` and the active task before working. Change only authorized files. Use a `codex/` branch, write tests with the change, run every task Verify command, commit the checkpoint and request an independent audit. Never push secrets, modify production schema manually or merge architecture-sensitive work without the §20.1 launch gates.
