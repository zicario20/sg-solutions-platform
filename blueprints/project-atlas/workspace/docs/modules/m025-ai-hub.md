# M025 - AI Hub, Specialist Skills and Agent Control

- Status: Provider-disabled technical foundation in progress; Product Owner acceptance pending
- Scope: policy control plane only

The M025 foundation defines agent scopes, model-provider modes, explicit tool allowlists and a global sensitive-tool denylist. Every provider mode currently resolves to a blocked decision. No model, Ollama runtime, cloud API, RAG, vector store, prompt, browser automation, social/voice channel, credential, queue, autonomous action or production traffic is active.
