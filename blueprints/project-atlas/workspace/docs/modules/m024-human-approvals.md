# M024 - Human Approvals and Sensitive Action Control

- Status: Provider-disabled technical foundation in progress; Product Owner acceptance pending
- Control: approval requests bind an action, policy version, reviewer separation and immutable payload hash

This foundation does not execute actions. It creates a local decision contract that rejects self-approval, duplicate reviewer approval, expired requests and payload changes between review and execution. Filing, tax submission, refunds, discounting, partner data sharing, exports and AI output remain disabled.
