# Module PRD — Design System

- Owner: Product Architect
- Status: Approved baseline (Product Owner, 2026-08-02)
- Catalog modules: M086–M088 (documentary references only; not implementation authorization)

Goal: create the accessible visual foundation shared by the marketing site and authenticated application.

In scope: semantic tokens, typography, spacing, radii, focus, reduced motion and the first reusable UI primitive. Out of scope: final page mockups and dark mode.

Requirements: UI/UX Pro Max must persist `design-system/project-atlas/MASTER.md` before UI implementation; WCAG 2.2 AA contrast and 320px reflow are mandatory; controls use visible focus and 44x44px targets; raw component colors are rejected outside tokens; cyan and gold are not normal text on white/surface.
