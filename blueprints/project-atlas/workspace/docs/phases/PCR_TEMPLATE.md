# Phase Completion Report Template

- Owner: Product Architect
- Status: Active template
- Update rule: revise when release evidence or governance requirements change

Every report records status, date, version, responsible agent, objective, implemented behavior, created/modified files, database changes, APIs, UI, security, tests, performance, accessibility, SEO, known risks, limitations, pending work, next dependencies, rollback and final checklist. Evidence distinguishes executed checks from manual launch gates.
