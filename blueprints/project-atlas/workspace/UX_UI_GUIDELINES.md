# UX/UI Guidelines

- Owner: Product Design role, initially the Product Architect
- Status: Approved visual direction; component implementation begins only after an approved UI/UX handoff and Build gate
- Update rule: synchronize with design tokens and accessibility evidence

The visual character combines financial confidence, modern software clarity and restrained motion. Use generous whitespace, concise copy, strong hierarchy and few large text blocks. Support desktop, tablet, mobile, keyboard and 200% zoom.

Normal text requires 4.5:1 contrast; large text and component boundaries require 3:1. Cyan and gold are accents, not normal text on white or the light surface. Respect reduced motion.
