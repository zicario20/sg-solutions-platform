# Documentation rules

- La documentación aprobada prevalece sobre la conversación y el código hasta que el Product Owner autorice el cambio.
- Registra decisiones arquitectónicas en `DECISIONS.md` y ADRs; no borres historia de `PROJECT_MEMORY.md`.
- `PROJECT_STATE.md` contiene solo el estado actual y debe leerse en menos de dos minutos.
- Cada fase cerrada produce un Phase Completion Report con evidencia de validación.
- Ningún documento puede prometer resultados garantizados en crédito, préstamos, impuestos o vivienda.
