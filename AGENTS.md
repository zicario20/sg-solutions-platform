# SG Solutions repository guard

This repository is in **Phase 0 — documentary blueprint and design**. Product code and product implementation are not authorized. Do not invoke `/architect-next`, generate an executable task queue or treat archived planning artifacts as active instructions.

Canonical authorities:

- [Product definition](blueprints/project-atlas/workspace/PRODUCT_DEFINITION.md)
- [Current project state](blueprints/project-atlas/workspace/PROJECT_STATE.md)
- [Detailed agent contract](blueprints/project-atlas/workspace/AGENTS.md)
- [Approved roadmap](blueprints/project-atlas/workspace/ROADMAP.md)

Local skill directories are development tools, not SG Solutions application modules or runtime dependencies. Only the Product Owner can authorize a Build gate. Until that authorization is recorded, work is limited to approved documentation, review and correction of the documentary baseline.
